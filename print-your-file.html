What We Can Print

The license decides.

Designers set the terms for their work, and printing a model for a paying customer is a commercial use. We only take jobs where that use is allowed.

We can print

  • Models under CC BY, CC BY-SA, or CC0
  • Any model whose page says commercial use is allowed
  • Models where the designer has given us written permission — we're happy to ask for you
  • Your own designs

We can't print (for payment)

  • Models with a non-commercial (NC) license
  • Models marked personal use only
  • Anything using trademarked characters or logos
  • Files where we can't verify the license or the source

Not sure what license a model has? Send it anyway and we'll look. Many designers say yes when asked, and if you'd like, we'll contact them for you.

Your Information
The Model
Heads up: we can't accept paid orders for non-commercial or personal-use-only models. You can still send this in — we'll get back to you about alternatives, such as asking the designer for permission.

If the model is a file rather than a web page, send the form and then email the file to sailoratlarge@stuffforsailors.com.

The Print
Quoted per job — calculated from filament cost, print time, and energy use. There's no design charge for an existing file. Ordering several? Multiples are usually discounted. You'll get a firm quote before any work begins, and a 50% deposit starts the job. The designer is credited on the quote and, if you like, on the part.

Designers: if you'd like your models offered through a print service — with credit, and a share of each sale — we'd like to hear from you.
